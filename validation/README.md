# Release validation

The v1.1.0 numerical pipeline runs nine steps, including the new matched-baseline reservation comparison. `analysis_report.json` records the execution environment, commands, checks and status. All original empirical data and parameter values are unchanged. The eight HSP numerical series read from CSV were checked against the prior plotting constants and match exactly.

The repository contains code, public source data and figure outputs only. It does not contain or compile the manuscript. Full Arial rendering has not been revalidated on the current host, where Arial is unavailable. Computational checks do not establish empirical causal identification.
